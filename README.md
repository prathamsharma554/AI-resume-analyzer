# AI Resume Analyzer & Matcher

A smart web application built using **Python**, **Streamlit**, **Matplotlib**, and **NumPy** that analyzes resumes against job descriptions to provide statistical compatibility insights.

## 🚀 Features
- **PDF Parsing:** Extracts text from resume PDF files instantly.
- **Keyword Extraction:** Identifies critical skills and terms from the job description.
- **Data Visualization:** Displays a graphical breakdown of matched vs. missing skills using Matplotlib charts.
- **Smart Recommendations:** Gives actionable suggestions on what to add to your resume to increase visibility.

## 🛠️ Tech Stack
- **Language:** Python
- **Frontend/Framework:** Streamlit
- **Data Processing:** NumPy, PyPDF2
- **Data Visualization:** Matplotlib
